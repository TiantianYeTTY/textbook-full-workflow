## ✨ 这是什么

`textbook-review-pdfs` 是一个 Agent Skill（智能体技能包），把"从一本教科书 PDF 产出两份高质量复习 PDF"的完整流程沉淀为可复用的工作流、脚本与踩坑经验。

它解决的问题非常具体：

- 手工整理一本几百页教材的知识点，耗时且容易遗漏；直接让 AI"总结一下"则常混入书外内容、公式显示为乱码或纯文本；
- 数学类教材的公式在 Markdown/网页里经常渲染不出来（裸露 LaTeX 源码），只有排版成 PDF 才有复习价值；
- 网上的复习资料不可溯源——本技能强制**每一条知识点、每一道例题都能在原书中检索到**，且交付前对**每一个计算结果做程序化复算**。

两份产出物：

| 产出 | 内容 | 用途 |
|---|---|---|
| 《书名 · 背诵合集.pdf》 | 全部定义/定理/公式 + 分布速查表 + 置信区间/检验汇总表 + 易混淆速记 | 背诵复习，不掺杂任何无关信息 |
| 《书名 · 教学文档.pdf》 | 书上完整原题 → 分析 → 第 1 步/第 2 步分步带做 → 方法总结 | 自学解题，看步骤就能学会 |

## 🎯 使用场景

当你的任务符合以下画像时，即可使用本技能：

| 要素 | 说明 |
|---|---|
| 输入材料 | 一本带文本层的教科书 PDF（数学/统计类已实测，其他理科教材同样适用） |
| 产出要求 | 两份复习 PDF：背诵合集 + 教学文档；公式 LaTeX 排版；每页 "Designed by TiantianYe" 水印 |
| 质量要求 | 内容全部溯源原书、严禁编造；交付前数值全部程序化复算 |

典型触发指令示例：

> 这是一本《XX》教科书PDF，请仔细阅读，所有知识参考都需要来自这本书、严禁摘取其他未经证实的信息。帮我做2份PDF：一份为核心公式、知识点的背诵合集（包含全书全部知识点和公式，供背诵复习，不允许掺杂无关信息）；一份为自学教学文档（包含书上例题及详细解题步骤，能教会我解题）。每一页PDF上方都要有"Designed by TiantianYe"的水印，所有公式用LaTeX排版，输出前务必严格校对。

## 🚀 使用方法（工作流概览）

技能按 6 个阶段自动执行，完整细节见 [SKILL.md](SKILL.md)：

| 阶段 | 内容 | 关键点 |
|---|---|---|
| 1. 提取原书 | `extract_book.py` 提取 PDF 全文并规范化（全角→半角、私用区编码→标点） | 脚本自动报告漏网字符；分批精读全书后才动笔 |
| 2. 撰写两份 md | 按定稿模板写背诵合集与教学文档 | 例题必须能溯源原书；题目完整、解析分步带做 |
| 3. 强制校对 | `numeric_check_template.py` 复算全部数值；`bare_math_scan.py` 扫描裸数学 | 两道关卡全过才准进入构建 |
| 4. 构建 HTML | `build_pdfs.mjs`（KaTeX 占位符方案） | 数学式在 Markdown 解析后才放回，避免被解析器破坏 |
| 5. 打印 PDF | Chrome headless（必带 `--no-pdf-header-footer`） | 控制台 `KATEX_ERROR` 必须为零 |
| 6. 水印+终验 | `watermark_verify.py` 加水印并四项验证（水印/超界/残留/页数） | 退出码 0 才可交付，且只交付 2 份 PDF |

## 🔧 环境依赖

- **Python 3** + `pymupdf`（提取、水印、验证）
- **Node.js**（任意近版本）+ `marked` + `katex`（HTML 构建，`npm install marked katex`）
- **Google Chrome**（headless 打印 PDF）
- 路径可用环境变量覆盖：`MARKED_PATH`、`KATEX_PATH`（见 `scripts/build_pdfs.mjs` 头部适配指南）

## ⚠️ 重要说明

- **内容溯源是红线**：所有知识点与例题必须来自用户提供的电子书，技能内置"原书溯源检索"工序；检索不到原题的例题会被替换为书中原题。
- **原书也会错**：校对发现原书印刷/计算错误时，产出物采信计算正确值并加注说明（实测中遇到 2 处原书数值错误）。
- **严禁跳过校对**：数值复算、裸数学扫描、PDF 四项验证任一未通过都不得交付。
- 教科书 PDF 必须带文本层；纯扫描件无法保证内容准确性，请先告知使用者。

## 🐛 已知踩坑点

以下是本项目实测踩过的坑，全部已沉淀为脚本内置逻辑或校验规则（完整档案见 [references/format-rules-and-errors.md](references/format-rules-and-errors.md)）：

1. **绝不要把 LaTeX 转成 Unicode 直排**（X̄、σ² 这类"看起来能读"的写法）。用户要 LaTeX 就是为了 PDF 渲染清晰；md 裸读难看的正解是交付渲染后的 PDF。
2. **扫描版教材的数字是全角+私用区编码**：小数点、带分数提取后会失真（如原书 1¾ 提取成 13/4），必须先规范化再核对，且靠数值复算兜底。
3. **KaTeX 必须用占位符方案**：把含 `$...$` 的 md 直接喂给 Markdown 解析器，`\{` 的反斜杠被吃、`_` `*` 被当斜体，公式全碎。
4. **Chrome 打印必带 `--no-pdf-header-footer`**，否则页眉页脚污染版面。
5. **PDF 溢出检测别用 DOM 测量**（公式容器宽度全不可靠），要在打印结果上用 pymupdf 检查文本块右沿。
6. **Python `\U` 转义必须正好 8 位十六进制**：`\U0001001b0` 是错误写法（9 位），映射永不生效且不报错。
7. **表格内绝对值要写 `\|` 转义**；`~~` 会渲染成删除线。
8. **给命令映射表加短命令前，先检查是否存在以它为前缀的更长命令**（`\big` 会截断 `\bigcup`）。
9. **每章另起页但首页不能空白**：教学文档第一章需紧随引言（`h1:nth-of-type(2) { break-before: auto; }`）。
10. **人工通读抓不到数值错误**：实测 5 处计算/提取错误全部由程序复算发现。

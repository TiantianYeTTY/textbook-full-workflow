# 两份交付文档的结构规格（定稿模板）

> 以下结构是用户验收通过的定稿规格（概率论项目 79 道例题 + 全书公式合集）。
> 换学科时**保持结构骨架与栏目语言不变**，只替换学科内容。

---

## 文档一：核心知识点背诵合集（split=h2）

**定位**：纯知识点列表，看着它就能背诵复习全书。**不允许掺杂无关信息**（R8）。

```
# <书名> · 全书知识点与公式背诵合集   ← 文档总标题（h1，仅 1 个）
> 一句话说明：全部知识点与公式取自《书名》（作者/出版社），供背诵复习。

# 第一章 <章名>                    ← 每章一个 h1……不对，背诵合集用 h2 分章
```

**实际定稿骨架**（背诵合集分章用 **h2**，构建时 split=h2）：

```
（文档头：总标题 + 来源说明 blockquote）
## 第一章 <章名>
### 1.x <节名>
- 定义/定理条目：**术语**：$LaTeX 公式$ —— 一句话解释
- 性质列表、公式推导结论（全部 $...$ 包裹）
（章内"小结"若有则并入条目）
## 第二章 ……（每章另起页）

## 常用分布速查总表（来自原书附录，逐行核对）
| 分布 | 记号 | 密度/分布律 | 期望 | 方差 |

## 置信区间汇总表 / 假设检验拒绝域汇总表（统计类学科）
| 情形 | 枢轴变量 | 双侧 | 右侧 | 左侧 |   ← 表内绝对值写 $\lvert \cdot \rvert$ 或 \|Z\|

## 易混淆知识点速记（N 条，每条一句话对辨）
```

要点：
- 每条知识点 = **术语 + 公式 + 一句话解释**，可背诵粒度；
- 汇总表是背诵合集的效率核心，全部来自原书附录/正文汇总；
- 末尾"易混淆速记"帮助对比记忆（如互斥 vs 独立）。

## 文档二：自学教学文档（split=h1）

**定位**：看了它就能自学这门课解题。例题全部来自原书，解析分步带做。

```
# <书名> · 自学教学文档            ← 总标题（h1）
> 使用说明：例题全部选自原书正文；建议遮住解答先自己做，再对照分步解析。

# 第一章 <章名>                    ← 分章用 h1（构建时 split=h1）
## 1.1 <节名>
### 概念要点
- 本节解题必需的定义/公式（与背诵合集呼应，更精简）

### 例题 N（教材例 M）<一句话题目标题>
**题目**　<书上完整原题，一字不落，含全部数据列表/分布表/图示描述>

**分析**　<讲思路从哪来：为什么这么做、突破口是什么>（可选，应用题必写）

**解**
**第 1 步：<做什么>。** <怎么做 + 为什么>
<公式 $...$ / $$...$$>
**第 2 步：……**
……
**第 k 步：<下结论>。** <完整结论句>

> **方法总结**：<本题可迁移的套路，一两句话>
```

要点（R7，来自用户反馈 F7）：
- **题目必须完整**："书上怎么写你怎么写"——数据列表、条件分布表、多问结构全部保留，禁止缩写成一句话；
- **解析分步带做**：每步"做什么 + 为什么"，把原书省略的中间步补出来（如积分限怎么定、为什么先算 P(AB) 再求条件概率、查哪个分位数）；
- **方法总结**收尾：提炼可复用的解题套路；
- 每章末尾（或全书末尾）设**综合题型套路链**：把跨节的高频综合题解法串成链。

## 分页与编号约定

| 项 | 背诵合集 | 教学文档 |
|---|---------|---------|
| 分章标题 | `## 第N章`（h2） | `# 第N章`（h1） |
| 构建 split | h2 | h1 |
| 分页 | 每章另起页 | 每章另起页，**第一章紧随引言**（E10：首页不能大片空白） |
| 例题编号 | —— | 文档内连续编号（例题 1..N），并标注（教材例 M）溯源 |
| 强调色 | 蓝色系标题条 | 同左 + 黄色方法总结框 |

## 内容红线（重申）

1. 每道例题可溯源原书（标注教材例 M），检索不到原题 = 删或换（E8）；
2. 原书数值错误 → 采信计算正确值 + 加注（E6/E7）；
3. 原书繁杂/无关内容可剔除，但**不得改变知识本身**；
4. 全部数学 = 标准 LaTeX（R1/R2）。

# 校对纪律（R5 的执行细则）

> 硬规则：**严禁不经校对输出**。本项目实测：5 处真实数值错误（E3-E7）全部由程序复算发现，
> 人工通读一遍都没抓到。校对 = 下面四道工序全部完成且通过。

## 一、原书数字解码（提取即失真，先规范化再核对）

扫描版教材 PDF 的数字有三种失真，核对前必须先解码（extract_book.py 已内置）：

| 失真类型 | 表现 | 解码 |
|---------|------|------|
| 全角数字 | ０.５０７ | 全角→半角映射 |
| 小数点变 PUA | `64􀅰8` 实为 64.8 | 数字之间的私用区字符 → `.` |
| **带分数丢空格** | 原书印 1¾，提取后变 `13/4` | ⚠ 无算法解法，靠数值复算暴露（E3 就是这么抓到的：复算 7/4 ≠ 文档 13/4，回查原书原文才知是带分数） |

**原书溯源检索**（确认例题出处时）：数字用容错正则匹配，`0.507` 应写成 `[0-9PUA][.PUA][0-9PUA]...`——见 extract_book.py 的 PUA_RANGE。

## 二、数值复算（numeric_check_template.py 模式）

对文档中**每一个**计算结果（概率值、期望方差、区间端点、检验统计量、χ² 值……）：

1. **精确复算**：组合数/级数/递推，误差容忍按位数设（4 位小数表值 1e-4）；
2. **数值积分**：分段/复杂积分用梯形法（n=20000，精度 1e-6 足够）；
3. **蒙特卡洛旁证**：期望/概率类再给一条独立旁证（seed 固定，容忍 1e-2）；
4. **查表值**（Φ(x)、t/χ²/F 分位数）视为已知常量直接比对。

**判定**：
- 复算 = 文档值 → ✓；
- 复算 ≠ 文档值 = 复算 ≠ 原书值 → 文档抄错了，改文档；
- 复算 ≠ 原书值，复算 = 可推确值 → **原书印刷错误**：文档采信计算正确值并加注（E6/E7）；
- 分段函数/分布函数：额外做**边界自检**——相邻分支在边界点取值必须相等（E5：x=2y 处 F 应衔接 y⁴）。

## 三、内容溯源核对（R4）

1. 每道例题在原书全文中用容错正则检索题面关键词（数字 + 术语），确认存在且数据一致；
2. 检索不到 = 可能是自行编造 → **立即替换为书中原题**（E8：例 13 换成三只箱子）；
3. 背诵合集的分布表/汇总表与原书附录逐行比对（本项目曾因此补上遗漏的伽马分布、贝塔分布两行）。

## 四、结构与渲染质检

| 工序 | 工具 | 通过标准 |
|------|------|---------|
| 裸数学扫描 | `bare_math_scan.py <md>...` | 命中归零 |
| 数学块闭合 | 扫描器内含 | 无未闭合 `$$` |
| 表格完整性 | 数学感知状态机逐格查（单元格内 `$` 配对 + 列数一致） | 零问题 |

| PDF 超界/残留/水印 | `watermark_verify.py` | 四项全 ✓，退出码 0 |
